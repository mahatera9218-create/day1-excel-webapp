## 1. 추진 배경

### 1-1. 현황

해외법인 분기실적은 현재 엑셀 파일(`해외법인_분기실적_2026.xlsx`) 형태로 관리·배포되고 있다. 실제 파일은 **120개 법인 × 19개 항목**의 원장 형태로, 다음과 같은 구조적 한계를 갖는다.

- 제목 배너·그룹 헤더가 상단 4개 행을 차지해 데이터 시작 위치가 파일마다 다르다
- 지역·사업부문·분기별 실적이 한 시트에 평면적으로 나열되어, 집계 관점의 판단이 불가능하다
- 파일 하단에 `ANNUAL TOTAL` 같은 합계 행이 섞여 있어 단순 집계 시 수치가 왜곡된다

### 1-2. 문제 정의

| # | 문제 | 영향 |
|---|---|---|
| P1 | 실적 파악에 수작업 피벗·필터가 매번 필요 | 보고 준비 시간 소요, 담당자별 산출물 편차 |
| P2 | 지역별·분기별 추세를 한눈에 볼 수 없음 | 실적 이상 징후의 발견 지연 |
| P3 | 합계 행 포함 등 집계 실수 가능성 상존 | 잘못된 수치가 보고에 반영될 위험 |
| P4 | 엑셀 열람 환경에 의존 | 파일 미보유자와의 정보 비대칭 |

## 2. 사업 목표

### 2-1. 핵심 목표

> **엑셀 파일을 업로드하는 것만으로, 별도 가공 없이 해외법인 실적 현황을 시각적으로 즉시 파악한다.**

### 2-2. 세부 목표

| 목표 | 설명 |
|---|---|
| G1. 즉시성 | 파일 업로드 후 추가 조작 없이 핵심 지표·차트가 자동 생성 |
| G2. 정확성 | 합계 행 등 비데이터 행을 자동 배제해 집계 오류 방지 |
| G3. 접근성 | 설치·로그인·서버 없이 브라우저만으로 이용 |
| G4. 탐색성 | 검색·필터로 관심 법인/지역을 즉시 확인 |

## 3. 대상 사용자

| 구분 | 사용자 | 주요 니즈 |
|---|---|---|
| 1차 | 해외법인 관리 담당자 | 월·분기 실적 취합 및 이상치 확인 |
| 2차 | 사업부문 기획 담당자 | 지역별·부문별 실적 비교 |
| 3차 | 보고 수신자(팀장·임원) | 요약 지표의 빠른 열람 |

---

## 4. 사업 범위

### 4-1. 범위 내 (In Scope)

- 로컬 `.xlsx` 파일 업로드 및 브라우저 내 직접 파싱
- 첫 번째 시트의 원본 데이터 표 표시
- 핵심 지표 4종(총 매출, 총 영업이익, 평균 영업이익률, 법인 수) 산출
- 차트 3종(지역별 매출, 분기별 매출 추이, 법인별 영업이익) 제공
- 데이터 검색 및 지역 필터
- 데스크톱·모바일 반응형 화면

### 4-2. 범위 외 (Out of Scope)

| 제외 항목 | 사유 |
|---|---|
| 백엔드 서버 / 데이터베이스 | 본 과제는 무백엔드 구성이 전제 |
| 사용자 인증·권한 관리 | 로컬 파일 기반 단독 실행 도구 |
| 데이터 영속화(저장·이력관리) | 업로드 세션 내에서만 처리 |
| 원본 엑셀 편집·역방향 저장 | 조회 전용 도구 |
| 두 번째 이후 시트(요약 시트) 활용 | 첫 번째 시트 기준으로 한정 |
| PDF/PPT 등 보고서 내보내기 | 차기 과제로 이관 |

## 5. 기대 효과

| 구분 | 효과 |
|---|---|

| 정량 | 합계 행 오집계 등 수치 오류 발생 여지 제거 |

| 정성 | 엑셀 숙련도와 무관하게 동일한 품질의 현황 파악 가능 |

## 6. 제약 조건 및 가정

### 6-1. 제약 조건

| # | 제약 |
|---|---|
| C1 | 백엔드 서버 및 데이터베이스를 사용하지 않는다 |
| C2 | 엑셀 파싱은 브라우저에서 클라이언트 사이드로 수행한다 |
| C3 | 엑셀 파싱은 `xlsx`, 차트는 `recharts` 라이브러리를 사용한다 |
| C4 | 프론트엔드는 React + Vite로 구성한다 |
| C5 | `run.bat` 실행만으로 기동 가능해야 한다 |

### 6-2. 가정

| # | 가정 |
|---|---|
| A1 | 분석 대상 데이터는 첫 번째 시트에 존재한다 |
| A2 | 실적 컬럼은 `법인명`, `지역`, `Q1~Q4매출`, `연매출`, `연영업이익` 명칭 체계를 따른다 |
| A3 | 업로드 파일은 사내에서 생성된 신뢰 가능한 파일이다 |
| A4 | 이용자는 최신 브라우저(Chromium 계열 등)를 사용한다 |

## 7. 성공 지표

| # | 지표 | 목표 | 달성 현황 |
