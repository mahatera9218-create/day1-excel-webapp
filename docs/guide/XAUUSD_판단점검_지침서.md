# XAUUSD 시장판단 점검 지침서

> **이 문서의 용도**
> 사용자(데이 트레이더)가 터미널·프로파일의 수치를 보고 내린 판단을, 이 문서에 정의된 지표의 **실제 의미·계산식·한계**에 비추어 **논리적 합성(정합성)을 점검**하기 위한 레퍼런스다.
> 사용자가 "지금 이러이러해서 이렇게 본다"라고 말하면, 아래 정의와 대조해서:
> 1. 그 지표를 **의미대로 해석했는가** (오해·과대해석 없는가)
> 2. **한계/함정**을 놓치지 않았는가
> 3. **자리·힘·방향**이 논리적으로 맞물리는가
> 를 검증하고, 어긋나면 지적한다. 사용자를 대신해 매매 결정을 내리는 문서가 아니라, **그의 읽기를 벼려주는** 문서다.

## 0. 전략 전제

- **종목**: XAUUSD(금). 단, 이 전략은 차트만 있으면 종목 무관(상품·외환·주식·코인). 현물이면 롱 자리만 봐서 더 단순.
- **스타일**: 데이트레이딩. 매매는 하루 1~2회. 엥걸핑(engulfing) 기반.
- **셋업 순서**: **방향 → 자리 → 힘** (이 순서가 논리적 기준. 힘이 자리보다 먼저 오지 않는다).
- **전략 정체성**: 엥걸핑 리테스트는 **두 종류** — ①눌림(추세 방향, continuation) ②역추세 fade(평균회귀, reversal). **국면 배지(추세/횡보)로 어느 쪽인지 먼저 판정**하고 그 국면에 맞는 종류만 친다. (강추세장 역추세 fade = 관망. §3.8)
- **매물대 관점**: 매물대(두꺼운 곳)는 지지/저항선이 **아니라 관망 구간**. 진입은 **경계**에서, 익절은 **다음 매물대/POC**에서. (§3.2·§3.6)
- **시간대 습관**: 아시아 10~16시(중국 기준) 주로, 최근엔 아시아 마감 무렵. 런던·뉴욕은 23시 취침 전까지만. **월요일 아시아·금요일 뉴욕은 회피.**
- **도구는 보조, 판단은 사용자**. 도구가 판단을 대신하지 않는다.

## 1. 시스템 구성 (두 도구)

| 도구 | 역할 | 데이터 경로 |
|---|---|---|
| **프로파일 앱** (메인 엔진) | 자리(매물대) + 힘(밀도·효율·델타) | MT5 EA(프로파일EA) → getpantry → 웹앱 |
| **터미널/대시보드** (보조) | 방향 맥락 + 레벨(여력)·TPSL | MT5 EA(대시보드) → getpantry/텔레그램 |

- 둘 다 **관찰 전용 EA**(매매 안 함). 15초 주기 전송.
- 프로파일이 자리+힘을 한 화면에 담아 사용자의 **메인**. 터미널은 방향·여력 곁눈질용 **보조**.

## 2. 프로파일 앱 — 지표 정의 (정확한 계산식)

### 2.1 매물대 / 틱 프로파일
- 가격을 **$2 버킷**으로 나눠, 각 버킷에서 발생한 **틱 수**를 누적한다.
- 범위: D1 봉 고저 기준, 최대 60버킷(초과 시 현재가 중심 클램프).
- 두 창을 동시에 표시:
  - **3D**(장기, `InpW3Days=3`): 최근 3일 누적. ※ 브로커가 틱을 3일만 보관해서 3으로 맞춤.
  - **1D**(단기): 최근 1일 누적.
- **POC (Point of Control)** = 그 창에서 **틱이 가장 많았던 버킷** = 가장 강한 벽·자석. 3D POC, 1D POC 각각 표시.
- **막대 길이** = 그 버킷 틱수 ÷ 최다 버킷 틱수 (공통 스케일). 밝은 색 막대 = POC.
- **빈 칸(막대 안 참)** = 그 가격대 틱이 적음 = 관심 덜 쏠린 구간. 연속된 빈 구간 = **진공(thin zone)**.

**의미**: 매물대는 "시장이 실제로 거래한 곳"의 실측 발자국. 두꺼운 곳 = 지지/저항, 얇은 곳 = 가격이 빠르게 통과.

### 2.2 Δ (델타, 체결우위)
- 버킷별 **(매수틱 − 매도틱) / 총틱 × 100 (%)**.
- 매수/매도 판정: 브로커가 TICK_FLAG_BUY/SELL를 주면 그대로. 없으면 **틱룰 폴백**(체결가가 ask쪽=매수, bid쪽=매도).
- **의미**: 그 가격대에서 **공격적으로 스프레드를 넘은 쪽(aggressor)**이 어디였나.
- **⚠️ 한계**: 델타는 "누가 공격했나"만 안다. **순수 매수수요 vs 매도물량 바이아웃(흡수)을 구분 못 한다.** → 반드시 "델타 대비 가격이 실제로 움직였나"와 같이 봐야 한다.

### 2.3 밀도 (혼잡도) — 봉별, 분당 정규화
```
밀도 = (봉의 틱수) ÷ (고가 − 저가) ÷ (봉 길이, 분)   [단위: 틱/$·분]
```
- **고저폭 기준**(net 아님). 봉길이(분)로 나눠 **TF 무관 비교 가능**.
- **높음(빡빡)** = 좁은 범위에 틱이 몰림 = **치열/흡수/저항**.
- **낮음(술술)** = 넓게 움직임 = **자유이동/진공**.
- 판정은 **같은 TF의 직전봉 대비**(현재 M15 vs 직전 M15). ±25% 밴드로 빡빡/보통/술술.

### 2.4 순이동 (net)
```
순이동 = |종가 − 시가|   (방향 ▲▼은 종가>시가 여부)
```
- 그 봉이 **결국 얼마나·어느 쪽으로** 갔나. 밀도와 독립.

### 2.5 효율 (방향 합의)
```
효율 = 순이동 ÷ 고저폭 × 100 (%)   = 캔들 몸통비율
```
- **100%** = 시가→종가 일직선(꼬리 없음) = **완전한 방향 합의**(적은 저항으로 쭉).
- **낮음** = 꼬리 길고 왕복 = **합의 없음**(싸움/거부).
- **의미**: "지금 방향을 믿어도 되나?"의 척도. Kaufman 효율비율과 같은 개념.
- **⚠️ 낮음 = "반드시 뒤집힘"이 아니라 "방향 미확정·신뢰 금지"**. 결과는 반전 / 눌림 / 결국 돌파 중 하나. 반전 확정은 자리·밀도와 겹칠 때(아래 3.5).

### 2.6 멀티TF 밀도 5줄 (화면 구성)
위→아래로 큰 흐름에서 지금으로 줌인:
```
직전 H4 · 직전 H1 · 현재 H1 · 직전 M15 · 현재 M15
```
각 줄: **밀도(틱/$·분) · 방향▲▼ · 순이동$ · 효율%**
- **직전(완료봉)** = 마감된 그 캔들 하나. **마감되면 값 고정**(포인터만 다음 캔들로 이동).
- **현재(진행봉)** = 실시간 변동. 마감 시 값이 굳어 "직전"으로 내려앉음.

## 3. 해석 프레임워크 (판단 정합성의 핵심 기준)

### 3.1 셋업 순서: 방향 → 자리 → 힘
1. **방향**: 어디로 가야 정상인가 (H4 추세 감각. 프로파일은 방향을 직접 안 줌 → 밀도 방향▲▼은 힌트만).
2. **자리**: 여력이 있나 소진됐나 (매물대/진공, 위·아래 매물대까지 거리).
3. **힘**: 실제로 그쪽으로 실리나 (밀도·효율·델타).

### 3.2 자리 (Zone)
- **매물대 안(두꺼움)** = 갇힌 자리. 위아래 튕기는 공방 → 추격 위험.
- **진공(얇음)** = 달릴 자리. 방향 잡히면 다음 매물대까지 직행.
- **숏 자리 보면 아래 레벨까지 거리 = 여력, 위 레벨 = 리스크**(반대도 동일). 레벨이 손절선 안쪽이면 안전, 멀면 손절 나갈 수 있음.

### 3.3 힘 — 2×2 원판 (틱 × 움직임)
| | 순이동 큼 | 순이동 적음 |
|---|---|---|
| **틱 많음** | 매우 활발(강한 방향성) | **치열/흡수**(상하 공방) |
| **틱 적음** | 진공·추세(빠르게·합의) | 한산(참여자 없음) |
- 밀도(틱÷고저폭)는 세로축(치열도), 순이동은 가로축(진행). **둘을 쌍으로 읽어야** 2×2가 복원됨.

### 3.4 3축 조합 (밀도 · 효율 · 방향)
- **효율 高 + 밀도 低** = 적은 틱 일직선 = **강한 진공 추세**(제일 깨끗한 방향).
- **효율 低 + 밀도 高** = 좁게 북적이며 제자리 = **치열 공방**.
- **효율 低 + 밀도 低** = 넓게 왕복 후 원점 = **휩쏘/거부**.
- **효율 高 + 밀도 高** = 좁은데 끝에 몰려 결판 = **돌파 직전/직후**.

### 3.5 흡수 vs 진공 vs 휩쏘 판정 (델타·밀도·가격반응)
- **진짜 매수수요**: Δ(+) 강함 **+ 가격 상승** → 따라가기 유리.
- **흡수(absorption)**: Δ(+) 강함 **+ 가격 정체** → 반대편이 다 받아냄 → **반전 경계, 추격 자제**.
- **바이아웃 후 소진**: Δ(+) → 벽 하나 먹고 되밀림.
- 핵심 원리: **"델타 큰데 가격 안 감 = 반대편에 숨은 큰 손이 받고 있다."**

### 3.6 목적지 로직 (가격은 어디로 가나)
- 매물대에서 **벗어나 있으면** → **POC로 회귀**(자석).
- 매물대를 **돌파하면** → 빈 공간(진공) 통과 → **다음 매물대까지 직행**.
- 진공 = 고속도로, 매물대 = 톨게이트. **목적지는 늘 다음 두꺼운 매물대**.
- **진공 상승 조건**: 위 매물대 없음 + 매수 유지(강할 필요 없음) → 적은 힘으로 계속 오름. 단 매수 끊기면 아래도 얇아 되밀림 빠름(양날검).

### 3.7 반전 신호 (효율 낮음 + 겹침)
효율 낮음 하나로는 반전 아님. 아래가 겹치면 반전 확률↑:
- 효율 低 **+ 매물대 도달 + 밀도 高(빡빡)** = 저항서 흡수 못 뚫음 → **반전 경계 강함**.
- **직전 고효율 추세 → 갑자기 효율 뚝** = 모멘텀 소진 → 추세 끝/눌림.
- 효율 低 **+ 긴 꼬리(왕복) + 방향 거부** = 되돌림.

### 3.8 국면 매칭 (엥걸핑 두 종류 구분)
같은 엥걸핑도 **국면·방향에 따라 정체성이 정반대**. 국면 배지(추세/횡보)를 먼저 읽고 종류를 고른다:

| 국면 배지 | 허용 엥걸핑 | 성격 | 익절 |
|---|---|---|---|
| **추세** | 추세 방향 **돌파·눌림**(continuation) | 추세 지속 | 크게(추세 재개) |
| **횡보** | 레벨서 **거부 fade**(reversal) | 평균회귀 | 타이트(스냅백) |

- **비대칭 원칙**: "강추세인데 역추세 fade(큰 손절)"의 대가 ≫ "레인지인데 관망(기회 놓침)". → 애매하면 관망 쪽.
- 배지 임계값 = H4·H1 효율 평균 ≥ 50 → 추세, 미만 → 횡보. (관측으로 캘리브레이션 대상)
- 규칙: "강추세 = 무조건 쉼"이 아니라 **"강추세 = 그 추세를 거스르는 fade 금지"**. 추세 방향 되받기는 허용.

## 3-B. 엥걸핑 셋업 확정 규칙 (진입 전 4단계 체크)

> 꼬리 기준 애매함의 최종 결론: **캔들은 느슨하게(방아쇠), 엄격함은 자리·국면·힘에 둔다.**
> 사용자가 "엥걸핑 잡았다"고 하면 아래 4개가 **모두 같은 방향**을 가리키는지 대조한다.

1. **방아쇠 — 몸통 엥걸핑(느슨)**: 직전 몸통을 현재 몸통이 감쌈. **꼬리 무시**, 단 **반대 꼬리 > 몸통이면 감점**.
2. **자리 — 객관 레벨 ±$3 근접(엄격)**: 전일/전주/금주 고저·세션 고저·라운드피겨·POC/매물대 경계 = **패널 자리 카드에 뜨는 것만**. **합류일수록 강함(주간>일간>세션)**. 허공 엥걸핑 = 셋업 아님.
3. **국면 — 배지 일치(필수 게이트)**: 횡보→거부 fade / 추세→돌파·눌림. 안 맞으면 **패스**(§3.8).
4. **힘 — 밀도·효율 확인**: 정체(빡빡)=흡수→fade 우호 / 원활(술술)=진공→돌파 우호.

**한 줄**: 몸통 엥걸핑 + 객관 레벨 근접(합류↑) + 국면 일치 + 힘 확인 → 네 개 정렬 시에만 진입.

> **점검 시**: 4개 중 빠진 축이 있으면 지적. 특히 ②객관 레벨 없이 방아쇠만으로, 또는 ③국면 배지와 반대 방향 엥걸핑을 치려 하면 강하게 제동.

## 3-C. 엔트리 등급 — 공격/수비 분할 진입

> 문제의 정체: "존 도달했는데 다음 캔들에 바로 전환·질주하는 걸 재다가 놓침" → 그 놓침의 감정.
> 해결: **공격이냐 수비냐 고르지 말고, 1R을 쪼개 둘 다 한다.** (scale-in)
> 진위(효율·틱·장악률)는 go/no-go가 아니라 **"공격 엔트리를 허락할지"를 정하는 스위치**다.

### 두 트랜치 (예: 0.04랏 → 0.02+0.02)
| 트랜치 | 시점 | 방식 |
|---|---|---|
| **공격 (½)** | 존 첫 도달·첫 신호에 **즉시** | **기계적 트리거**(재량 금지). 2번 전략(객관 레벨)=**레벨에 지정가 미리 걸기**. 1번(H1 엥걸핑 존)=**첫 M15 거부/엥걸핑 마감에 즉시**, 2차 확인 안 기다림. |
| **수비 (½)** | **확인** 받고 추가 | M/W 2봉우리(오른쪽 봉우리/바닥)·리테스트 홀드·H1 진행방향·봉 마감시간·일/세션 추세 종합. (기존 프로세스 그대로) |

### 효과 (비대칭 개선)
- **한 캔들 전환·질주** → 공격분 무조건 타 있음 = **완전 놓침 없음**(감정 해소). 단 수익도 ½.
- **확인 주고 감** → 공격+수비 풀사이즈, 평단 유리.
- **가짜·실패** → 공격분 작아 피해 제한(½R) + 수비분 미발동.
- → 못 탐도 털림도 **반쪽**이 된다. 총 리스크는 그대로(공격 0.5R + 수비 0.5R = 1R, **2R 아님**).

### 진위 스위치 (§3-B·§2.5 연동)
- **효율·틱수·몸통 장악률 높음** → **공격 허락**(일찍, 지정가·첫 캔들).
- **애매함** → **수비만**(확인 후) 또는 스킵.
- 진위 정량 후보: 몸통장악률(body2÷body1 ≥1.0, 강함 ≥1.3) · 효율(몸통비율 ≥~60%) · 마감위치(방향쪽 상/하단 25%) · 틱수(직전 동TF ≥1.2배). **임계값은 실매매 로그로 캘리브레이션**(승 vs 패/놓침 가르는 값).

### 본절(BE)·손절 관리 — **진입은 둘, 관리는 하나**
- **손절선 하나**: 공격·수비 모두 **구조(존/엥걸핑 꼬리) 아래 같은 선**. 수비 추가돼도 손절선 불변.
- **평단 하나**: 두 트랜치 평균가 기준.
- **본절 하나**: 기존 BE 규칙을 **평단 기준**으로 적용 → 트리거 시 손절선 하나를 평단으로 이동.
- ❌ **트랜치별 개별 본절 금지**: 수비 추가 시 평단 변해 재계산 지옥 → 모바일 재량·실수 유발.

**한 줄**: 공격(기계적·즉시·½) + 수비(확인·추가·½)로 1R을 쪼개 진입하고, **손절·본절은 평단 기준 하나로** 굴린다. 공격 엔트리 허락 여부는 진위 점수가 정한다.

> **점검 시**: 공격분을 재량으로 미룬 정황(=재다가 놓침), 또는 트랜치별 개별 본절로 꼬인 정황을 짚는다. 진위 낮은데 공격 엔트리 친 것도 제동.

## 4. 터미널/대시보드 — 지표 정의 (보조)

- **방향강도(추세율)**: 세션/일간/주간 각각 O/H/L/C 기반으로 방향 세기를 % 산출. 절대적 방향 신호가 아니라 파생 지표(다소 주관적).
- **세션 상/하단, 레벨**: 세션 히스토리 평균(최근 InpSessDays=5일, M5 봉 기반)으로 평균 상방·하방 폭을 구해 시가 기준 **1차 레벨(50%)·최종 레벨(100%)** 산출.
- **도달률(%)**: 시가→현재가가 그 레벨(가격 이동한 쪽)까지 몇 % 왔나. 100% 초과 = 돌파.
- **체결우위(델타)**: 최근 **4시간** 틱의 매수−매도 우위. (프로파일 델타와 달리 시간창 기준)
- **틱볼륨%**: 현재 세션/봉 틱수 ÷ 평균 대비.

**용도**: 방향 맥락 + "레벨까지 여력(TPSL)" 감. 세부 힘 판단은 프로파일이 우위.

## 5. ⚠️ 한계·함정 (판단 점검 시 반드시 대조)

1. **브로커 틱 3일 보관** → 프로파일 장기창은 **3D까지만** 신뢰. 그 이상은 데이터 없음.
2. **틱수 = 진짜 거래량 아님**. 외환/금은 분산시장이라 MT5 틱은 **볼륨 근사치**. 주식(거래소 집중 실볼륨)보다 노이즈 큼.
3. **진행봉 시작 직후 밀도 불안정**: 경과시간이 몇 초면 분모가 바닥값(0.5분)으로 눌려 밀도 뻥튀기. **봉 몇 분 지난 뒤 값으로 판단**.
4. **델타의 한계**(2.2): aggressor만 앎. 흡수/순수수요 구분은 **가격반응 병행 필수**.
5. **밀도는 고저폭 기준**(net 아님). "한 번 왕복"과 "그 폭 안 여러 번 왕복"은 못 가림(그건 total path 기준이라야 함 — 현재 미구현).
6. **직전=고정, 현재=실시간**. "직전 H1"은 매시간 다른 캔들을 가리키는 이동 포인터.
7. **TF간 비교**: 밀도는 분당 정규화라 비교 가능, 효율은 %라 비교 가능. **순이동(절대 $)은 TF마다 스케일 달라 직접 비교 금지**.
8. **뉴스·매크로 급변**: 프로파일·터미널 모두 예정 이벤트를 경고 못 함. 지표·아시아마감·주요시간 회피는 사용자 습관이 메움.
9. **레벨의 주관성**: 세션/일/주 레벨은 계산 파생값이라 라운드피겨·전고저처럼 "모두가 보는 자리"는 아님. 매물대(실측)가 더 객관적.

## 6. 논리 점검 체크리스트 (사용자 판단 검증용)

사용자가 판단을 말하면 아래를 순서대로 확인한다:

1. **지표 의미대로 썼나?**
   - 밀도 높음을 "활발"로 오해하지 않았나? (밀도 높음 = 치열/흡수, 활발은 순이동도 커야 함)
   - 효율 낮음을 "반전 확정"으로 단정하지 않았나? (= 방향 미확정)
   - 델타만으로 "매수 강함 → 오른다"고 하지 않았나? (가격반응 확인했나)
2. **자리·힘·방향이 맞물리나?**
   - 진공이라며 추격하는데 밀도/효율은 반대(빡빡·저효율) 아닌가?
   - 매물대 안인데 돌파를 전제로 진입하려는 건 아닌가?
3. **한계를 밟지 않았나?**
   - 3일 넘는 틱을 신뢰하나? 진행봉 초반 밀도로 판단하나? 순이동을 TF간 직접 비교했나?
   - 뉴스/회피 시간대인가?
4. **목적지 논리와 일치하나?** (POC 회귀 / 다음 매물대 / 진공 직행)
5. **반전 판단이면** 효율 낮음 외에 매물대+흡수 또는 고효율→저효율 급락이 겹쳤나?
6. **엥걸핑 진입이면 4단계(§3-B) 정렬됐나?** 몸통 방아쇠 + 객관 레벨 근접 + 국면 배지 일치 + 힘 확인. (특히 허공 엥걸핑 / 국면 역행 fade 제동)
7. **엔트리 등급(§3-C) 지켰나?** 공격분을 재량으로 미루다 놓치지 않았나(기계적 트리거 준수)? 손절·본절을 평단 기준 하나로 관리했나(트랜치별 개별 본절 금지)? 진위 낮은데 공격 엔트리 친 건 아닌가?

> 어긋나면: "그 해석은 지표 정의상 X를 의미하는데, 네 판단은 Y를 전제한다. 다시 보라"는 식으로 **구체적으로** 짚는다. 맞으면 "정합적"이라 확인하고, 놓친 축(예: 자리는 봤는데 효율 안 봄)이 있으면 보완을 제안한다.
