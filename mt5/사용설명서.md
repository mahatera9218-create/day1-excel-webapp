## 0. 이게 다 뭐예요? (전체 그림 한 장)

우리 도구는 **부품이 여러 개인 하나의 세트**예요. 자동차로 치면:

```
① 방향강도 터미널  = 계기판 (지금 어디로, 얼마나 세게 가는지)
② 체결 터미널      = 엔진 소리 (그 움직임을 실제 거래가 밀어주는지)
③ 판단 요약        = 내비게이션 요약 (위 둘을 합쳐 "지금 편향은 이쪽")
④ 인걸핑 알림      = 알람 (살 자리 신호가 뜨면 알려줌) + 품질 점수
⑤ 자동 기록기      = 블랙박스 (내가 언제 이기고 지는지 저장)
⑥ 대시보드/모바일앱 = 위 전부를 폰 한 화면에서 실시간으로
```

⚠️ **가장 중요한 원칙 (계속 나옵니다):**
이 도구들은 **"사라/팔아라"를 알려주는 게 아니에요.** "지금 상황이 이렇다"까지만 보여줘요.
**실제 진입은 항상 차트(캔들 = 인걸핑)를 보고 여러분이 판단**합니다. 도구는 보조, 차트가 본체.

## 1. 먼저 알아야 할 기본 개념 4개

### ① 캔들(봉)이 뭐예요?
가격이 일정 시간 동안 어떻게 움직였는지를 막대기 하나로 그린 거예요.

```
캔들 하나에는 4개 정보가 있어요:
  시가 = 그 시간 '시작'했을 때 가격
  종가 = 그 시간 '끝날' 때 가격
  고가 = 그 시간 중 '가장 높이' 간 가격
  저가 = 그 시간 중 '가장 낮게' 간 가격

    ┃ ← 위꼬리 (잠깐 여기까지 올랐다 내려옴)
   ┏┓
   ┃┃ ← 몸통 (시가~종가, 실제로 간 거리)
   ┗┛
    ┃ ← 아래꼬리 (잠깐 여기까지 내렸다 올라옴)
```

**예시:** "H4 캔들" = 4시간짜리 캔들 = 4시간 동안의 움직임을 막대 하나로.

### ② 핍(pip)이 뭐예요?
가격이 움직이는 **최소 단위**예요. 거리를 재는 '센티미터' 같은 거죠.

```
EURUSD에서 1핍 = 0.0001
예: 1.16500 → 1.16600 = 10핍 움직임
```

> 💡 골드(XAUUSD)를 쓰면 도구가 자동으로 단위를 바꿔서 **핍 대신 $/pt(포인트)**로 보여줘요. 심볼만 바꾸면 알아서 맞춰집니다.

### ③ 세션이 뭐예요?
하루 중 **어느 나라 시장이 활발한 시간대**인지예요.

```
아시아 세션 (한국 낮): 조용함, 잘 안 움직임
런던 세션 (한국 저녁): 활발함! ← 유럽 사람들이 거래
뉴욕 세션 (한국 밤): 활발함! ← 미국 사람들이 거래
```

**예시:** "런던 세션이다" = 지금 유럽이 거래하는 시간 = 가격이 잘 움직임.

### ④ 틱(tick)이 뭐예요? *(체결 터미널에서 씁니다)*
**가격이 한 번 바뀌는 것 = 틱 하나**예요. 거래가 일어날 때마다 가격이 깜빡깜빡 바뀌는데, 그 깜빡임 하나가 틱이에요.

```
틱이 많다 = 거래가 자주 일어남 = 활발
틱 하나하나에 "매수 쪽이었나 / 매도 쪽이었나" 표시가 붙어요
→ 이걸 세면 "지금 사는 사람이 많나, 파는 사람이 많나"를 알 수 있어요 (= 체결 터미널)
```

## 3. 핵심 개념 — "방향강도"

이 터미널의 **가장 중요한 값**이에요. 이것만 이해해도 절반은 끝나요.

### 방향강도가 뭐예요?
**"가격이 이리저리 흔들린 것 중에서, 실제로 한 방향으로 얼마나 갔나"** 를 %로 나타낸 거예요.

### 쉬운 비유 — 술 취한 사람이 집에 가기
```
술 취한 사람이 A에서 B로 걸어간다고 해봐요.

경우 1: 비틀비틀했지만 결국 B까지 쭉 감
  → 흔들린 거리 대비 실제 간 거리가 큼
  → 방향강도 높음 (예: 90%) = "방향 잡고 갔다"

경우 2: 이리저리 헤매다가 출발점 근처에서 끝남
  → 흔들리기만 하고 실제론 별로 못 감
  → 방향강도 낮음 (예: 20%) = "제자리 맴돌았다"
```

> **📐 계산식 & 해석**
> - **계산식:** 방향강도 = (종가 − 시가) ÷ (고가 − 저가) × 100
> - **부호:** `+`면 위(상승), `−`면 아래(하락). **숫자 크기** = 얼마나 세게 한 방향으로 갔나.
> - **추세율(=효율):** 방향강도에서 부호만 뗀 **절댓값**이에요. "방향은 빼고, 세기만" 볼 때 씀.
> - **해석:** 높으면 **추세**(한 방향으로 쭉), 낮으면 **횡보**(왔다갔다만). 값이 클수록 몸통이 크고 꼬리가 짧다는 뜻.

### 예시로 이해하기
```
[화면] 방향강도 98%  → "엄청 세게 한 방향으로 가는 중. 추세다. 기회 노려야지"
[화면] 방향강도 15%  → "그냥 왔다갔다. 횡보다. 지금은 쉬자. 애매하게 들어가면 물린다"
[화면] 방향강도 −38% → "아래로(하락) 방향강도 38짜리로 가는 중"
```

**왜 중요하냐면** — 여러분의 매매 방법은 "한 방향으로 갈 때" 잘 돼요. 그러니 방향강도가 높을 때(추세)만 노리고, 낮을 때(횡보)는 쉬는 거예요.

## 4. "시가대비 / 변동 고저·시종" — 얼마나 움직였나

화면의 `세션시가 1.16300 (시가대비 +0.17%)` / `변동: 고저 45핍 | 시종 +44핍` 부분이에요.

> **📐 계산식 & 해석**
> - **시가대비(%)** = (현재가 − 시가) ÷ 시가 × 100
>   → 시작가 대비 지금 몇 % 올랐나/내렸나. `+`상승 `−`하락.
> - **변동 고저(핍)** = (고가 − 저가) ÷ 1핍
>   → 그 구간에서 **위아래로 총 얼마나 출렁였나**(흔들린 총거리).
> - **변동 시종(핍)** = (종가 − 시가) ÷ 1핍  *(부호 포함)*
>   → **실제로 순수하게 간 거리**(시작→끝).
> - **해석:** 고저(출렁임)는 큰데 시종(순이동)이 작으면 → "많이 흔들렸는데 결국 제자리" = 횡보.
>   고저와 시종이 비슷하면 → "흔든 만큼 다 방향으로 감" = 강한 추세. (이 비율이 곧 방향강도예요.)

## 5. "평균 대비"는 왜 봐요?

화면에 `방향강도 98% (5일세션평균 34%)` 이렇게 나와요. 뒤에 붙은 **평균**이 왜 중요할까요?

### 비유 — 오늘 유난히 더운가?
```
"오늘 25도" 만 보면 → 더운지 모름
"오늘 25도 (평소 이맘때 15도)" → "와 오늘 유난히 덥네!"
→ 평균이랑 비교해야 '유난히'가 보임
```

> **📐 계산식 & 해석**
> - **평균** = 최근 N개 같은 종류 캔들의 **방향강도 절댓값 평균**.
>   (세션·일간 = 최근 5일치 / 주간 = 최근 4주치 기준)
> - **해석:** 지금 방향강도 > 평균 → "평소보다 센 추세, 오늘 유난히 방향 잡고 감".
>   지금 방향강도 < 평균 → "평소보다 밍밍, 횡보 같음, 쉬는 게 나을 수 있음".

```
[화면] 방향강도 98%, 평균 34% → 98 > 34 → "진짜 센 추세. 좋은 기회일 수 있다"
[화면] 방향강도 20%, 평균 34% → 20 < 34 → "오늘은 밍밍하네. 횡보 같다. 쉬자"
```

## 6. "레벨"과 "도달률" — 위아래로 얼마나 남았나

### 레벨이 뭐예요?
**"가격이 오늘 여기까지 갈 것 같다"는 예상 목표 지점**이에요. (위 레벨 / 아래 레벨 따로)

### 도달률이 뭐예요?
**"그 예상 목표를 지금 몇 % 채웠나"** 예요.

### 비유 — 목표까지 걸어가기
```
집에서 학교까지 1km (이게 '레벨')
  500m 왔으면 → 도달률 50% (반 왔다, 더 갈 여력)
  1km 다 왔으면 → 도달률 100% (도착, 멈추거나 돌아올 수도)
  1.2km 갔으면 → 도달률 120% (학교 지나쳐버림! 너무 감, 되돌림 조심)
```

> **📐 계산식 & 해석 — 레벨**
> 레벨은 **위/아래가 서로 다른(비대칭)** 폭으로 잡아요. "평소 이 기간에 위로 이만큼, 아래로 저만큼 가더라"의 평균이에요.
> - **평균 상방폭 avgUp** = 최근 N기간 (고가 − 시가)의 평균
> - **평균 하방폭 avgDn** = 최근 N기간 (시가 − 저가)의 평균
> - **세션 1차 레벨(50%):** 상단 = 시가 + 0.5 × avgUp / 하단 = 시가 − 0.5 × avgDn
> - **세션 최종 레벨(100%):** 상단 = 시가 + 1.0 × avgUp / 하단 = 시가 − 1.0 × avgDn
> - **일간·주간 레벨:** 상단 = 시가 + avgUp / 하단 = 시가 − avgDn *(단일 레벨, ×1.0)*
> - **의미:** "오늘/이번 세션에 평소만큼 움직인다면 여기까지"라는 **통계적 예상 목표**. 지지·저항 같은 개념.

> **📐 계산식 & 해석 — 도달률**
> 가격이 **움직인 쪽**의 레벨을 기준으로 봐요.
> - **도달률(%)** = (현재가 − 시가) ÷ (그 방향 레벨 − 시가) × 100
> - **100% 미만:** 아직 레벨 못 감 → **잔여 = (레벨 − 현재가)** 핍 만큼 남음.
> - **100% 초과:** 레벨을 넘어감(돌파) → **초과 = (현재가 − 레벨)** 핍 만큼 더 감.
> - **해석:** 50%=여력 많음(늦지 않음) / 100%=예상만큼 다 옴(멈춤·되돌림 주의) / 120%↑=과도(따라 사면 꼭지 위험).

```
[화면] 도달률 30%  → "위로 갈 자리가 아직 많이 남음. 늦지 않았다" (참고만)
[화면] 도달률 111% → "예상보다 더 감. 너무 많이 왔다. 따라 사면 물릴 수도. 조심"
```

## 7. "틱볼륨" — 지금 사람들이 얼마나 활발한가

### 틱볼륨이 뭐예요?
**"지금 시간대에 거래가 얼마나 활발한지"** 예요. (가격이 몇 번 움직였나 = 활동량)

⚠️ 주의: 이건 "얼마나 많이 샀나(수량)"가 아니라 **"얼마나 자주 움직였나(활발함)"** 예요.

> **📐 계산식 & 해석**
> - **틱볼륨(%)** = 지금까지 쌓인 틱 수 ÷ (같은 구간의 평소 평균 틱 수) × 100
> - 괄호 안 숫자(예: 25,136 Ticks) = **실제 틱 개수**(원본).
> - **해석:** 100%보다 크면 "평소보다 활발", 작으면 "평소보다 조용". 활발할수록 큰 움직임이 나올 확률↑.

```
[화면] 틱볼륨 41% → "지금은 평소보다 좀 조용하네"
[화면] 틱볼륨 90% → "엄청 활발. 큰 움직임 나올 수 있다"
```

## 8. 세션 / 일간 / 주간 — 왜 3개나 봐요?

같은 정보(방향강도·레벨 등)를 **3개의 시간 크기**로 봐요.

```
[1] 세션 = 지금 이 세션 (몇 시간) → 제일 작은 그림
[2] 일간 = 오늘 하루 → 중간 그림
[3] 주간 = 이번 주 → 제일 큰 그림
```

### 비유 — 지도 축소/확대
```
주간 = 나라 전체 지도 (큰 방향) / 일간 = 도시 지도 / 세션 = 동네 지도 (지금 당장)
→ 셋 다 봐야 "큰 방향 + 지금 상황"을 함께 앎
```

### 왜 3개 다 봐요? — **셋이 같은 방향이면 강한 신호, 다르면 조심.**
```
[좋은 예 - 다 상승]  주간↑ / 일간↑ / 세션↑ → "다 위를 보네. 상승 확실"
[조심 예 - 엇갈림]  주간↑ / 일간↓ / 세션↑ → "큰 방향이랑 오늘이 다르네. 애매. 조심"
```
> 💡 이 "몇 개가 같은 방향인지"를 자동으로 세서 위에 요약해주는 게 뒤에 나올 **판단 요약(다층 정렬)**이에요.

## 9. [4] H4 국면 — 여러분 매매의 핵심

이 부분이 **여러분 전략에서 제일 중요**해요. 여러분은 "H4로 큰 방향 보고 → 작은 데서 진입"하는 전략이거든요.

```
H4 = 4시간 캔들
완성 = 직전에 '끝난' H4 캔들의 방향강도 (확정된 큰 방향)
진행 = 지금 '만들어지는 중'인 H4 캔들의 방향강도 (경과 %와 함께)
H1 위치(5일범위) = 지금 가격이 최근 5일 고저 안에서 어디쯤(바닥이냐 천장이냐)
```

> **📐 계산식 & 해석 — H4 세부**
> - **완성 방향강도** = 직전 완성 H4 캔들의 (종가−시가)÷(고가−저가)×100. → 확정된 4시간 큰 방향.
> - **진행 방향강도** = 지금 진행 중 H4 캔들의 같은 계산(지금까지 값). **경과(%)** = 흐른 시간 ÷ 240분 × 100.
>   → 경과가 작을 때의 진행값은 아직 요동칠 수 있으니 참고만.
> - **H1 위치(%)** = (현재가 − 5일 저가) ÷ (5일 고가 − 5일 저가) × 100
>   → **0% = 5일 바닥, 100% = 5일 천장.** 80%↑ = 고점권(과열), 20%↓ = 저점권(과매도) → 되돌림 주의.

### 예시
```
[화면] 완성 +38% (평균 24%) 추세, 진행 +12%, H1위치 41%
→ 해석: "4시간 큰 그림이 상승 추세(평균보다 셈), 지금도 위로 진행 중, 위치는 중간"
→ 행동: "그럼 나는 '사는 것(롱)'만 노린다. 파는 것(숏)은 안 봄"
```

# 【터미널 ②】 체결 터미널 — "엔진 소리"

## 10. 체결 터미널이 뭐예요?

방향강도 터미널이 **"가격이 어디로 갔나(결과)"** 를 본다면,
체결 터미널은 **"그 움직임을 실제 거래가 밀어주고 있나(힘의 출처)"** 를 봐요.

### 비유 — 배와 노
```
방향강도 = 배가 실제로 어디로 갔나 (항적)
체결     = 사람들이 노를 어느 쪽으로 젓고 있나 (추진력)

→ 배가 앞으로 가는데(가격 상승) 노도 앞으로 젓고 있으면(매수 체결 우위)
   → "진짜 힘 있는 상승" (믿을 만함)
→ 배는 앞으로 가는데 노는 뒤로 젓고 있으면(매도 체결 우위)
   → "곧 멈추거나 밀릴 수 있음" (의심)
```

체결 터미널은 화면에 **3단계**로 나와요:
```
① 최근 4H 체결 역학 요약 → 큰 흐름 (지난 4시간 전체 압력)
② 자리 프레임(1H) 시계열 → 시간대별 흐름 (-3봉 → -2봉 → -1봉 → 진행봉)
③ 진입 프레임(5M) 완성 vs 진행 → 진입 타이밍용 (직전 완성봉 vs 지금 봉)
```

---

## 11. 체결 터미널 핵심 값들 (하나씩)

### ① 체결 우위 (매수 vs 매도)
**"지금 사는 손이 많나, 파는 손이 많나"** 를 줄다리기로 본 거예요.

> **📐 계산식 & 해석**
> - **체결 우위(%)** = (매수 틱 수 − 매도 틱 수) ÷ 총 틱 수 × 100
> - **부호:** `+`면 매수 우위(사는 쪽 많음), `−`면 매도 우위(파는 쪽 많음). 크기 = 한쪽으로 쏠린 정도.
> - **해석:** `+`가 크면 상승 압력, `−`가 크면 하락 압력. 가격 방향과 **같으면 신뢰**, 엇갈리면 주의.

```
[화면] 체결 우위 +5.2%  → "사는 쪽이 조금 더 많다"
[화면] 체결 우위 −7.5%  → "파는 쪽이 확실히 많다"
```

### ② 총틱 / 왜곡
> **📐 계산식 & 해석**
> - **총틱** = 그 구간에 일어난 체결(틱) 수 = 거래 활동량.
> - **왜곡(distort)** = 한쪽 호가만 비정상적으로 깜빡인 **잡음성 틱 수**.
> - **해석:** 왜곡이 총틱에 비해 많으면 → "지금 데이터가 좀 지저분함(신뢰 낮음)". 적으면 깨끗한 신호.

### ③ ↑ / ↓ (매수틱 / 매도틱)
그냥 매수 쪽 틱 수와 매도 쪽 틱 수를 그대로 보여줘요. (체결 우위의 원재료)

### ④ 실이동 / 흔들림(고저폭) / 효율
> **📐 계산식 & 해석**
> - **실이동(move)** = (종가 − 시가), 핍. → 실제 순수하게 간 거리(부호 포함).
> - **흔들림 = 고저폭(span)** = (고가 − 저가), 핍. → 위아래로 출렁인 총거리.
> - **효율(eff)** = |실이동| ÷ 고저폭  *(0 ~ 1)*
>   → 방향강도의 0~1 버전이에요. **1에 가까울수록 "흔든 것 없이 깔끔하게 한 방향"**, 0에 가까우면 "출렁이기만 함".

```
[화면] 실이동 +12핍 / 흔들림 15핍 / 효율 0.80
→ "15핍 출렁이면서 순수하게 12핍 위로 감 → 효율 0.8, 꽤 깔끔한 상승"
```

### ⑤ 틱당 실이동 (추진력)
**"한 번 거래될 때마다 가격을 얼마나 밀었나"** — 힘의 무게예요.

> **📐 계산식 & 해석**
> - **틱당 실이동** = 실이동 ÷ 총틱 수.
> - **해석:** 값이 크면(부호 포함) → **적은 거래로도 쭉 밀림 = 강한 추진력**.
>   0에 가깝거나 부호가 왔다갔다 → 많이 거래됐는데 안 밀림 = **공방/지침**(에너지만 쓰고 안 감).

### ⑥ 순이동 / 고저폭 (4H 요약)
4H 요약칸에 나오는 값. **순이동** = 4시간 동안의 실이동(순수 이동), **고저폭** = 4시간 전체 출렁임. 위 ④와 같은 개념을 4시간 크기로 본 거예요.

---

## 12. 왜 시계열(-3 / -2 / -1 / 진행)로 봐요?

체결 우위나 효율은 **한 순간만 보면 착각하기 쉬워요.** 그래서 최근 흐름을 시간순으로 늘어놓아요.

```
[자리 프레임 1H 시계열]
  -3봉: 매도우위 −0.8%  효율 0.59
  -2봉: 매도우위 −1.1%  효율 0.76
  -1봉: 매도우위 −3.5%  효율 0.84   ← 점점 매도 쪽으로 세지네
  진행: 매도우위 −5.5%  효율 0.77   ← 지금도 매도가 이어짐
→ 해석: "매도 압력이 시간이 갈수록 강해지는 흐름" = 하락에 힘이 실림
```

- **-3 / -2 / -1** = 직전에 **완성된** 1시간봉 3개 (과거 → 최근 순).
- **진행** = 지금 만들어지는 중인 봉.
- **진입 프레임(5M)** 은 더 잘게: **직전 완성봉(-1)** 과 **현재 진행봉**을 나란히 비교해서 "방금 전이랑 지금이 같은 방향인가"를 봐요. (진입 타이밍 잡을 때)

# 【③】 판단 요약 — "위 둘을 합친 결론 한 줄"

## 13. 판단 요약이 뭐예요?

대시보드 **맨 위**에 뜨는 요약이에요. 방향강도의 4개 층(세션·일간·주간·H4)을 **자동으로 종합**해서 "지금 편향은 어느 쪽"인지 한눈에 보여줘요. 카드 하나하나 안 봐도 되게.

```
┌───────────────────────────────────────────┐
│  ▼  하방 우위          정렬 4/4            │
│  4개 층 방향 종합 (세션·일간·주간·H4)      │
│ [H4 추세▼] [다층 정렬 4/4] [체결 −3.2%] … │
│  세션▼  일간▼  주간▼  H4▼                  │
│  • H4 하방 추세 + 다층 정렬(4/4).          │
│    같은 방향 인걸핑 자리를 우선 관찰할 국면 │
│  • 진입 확정은 캔들(인걸핑)에서.           │
└───────────────────────────────────────────┘
```

> **📐 계산식 & 해석 — 편향 / 다층 정렬**
> - **편향(표결):** 4개 층(세션·일간·주간·H4)의 방향강도 **부호를 셈**.
>   - 상승 층 수 vs 하락 층 수를 비교 → (상승−하락)
>   - `+2 이상` = **상방 우위**, `−2 이하` = **하방 우위**, `±1` = 약한 편향, `0` = **혼조**.
> - **다층 정렬(N/4):** 우세한 방향과 **같은 방향인 층의 개수**. 4/4면 완전 일치(강한 신호), 2/4면 반반(애매).
> - **맥락 가이드(문구):** 아래 규칙으로 자동 생성돼요(신호 아님, 상황 안내).
>   - H4 추세 + 정렬 3~4/4 → "같은 방향 인걸핑 자리 우선 관찰"
>   - H4 횡보 → "추세 신뢰도 낮음, 신중"
>   - 혼조(정렬 약함) → "관망 우위"
>   - ⚠ 체결 방향이 편향과 반대 → "진입 서두르지 말 것"
>   - ⚠ H1 위치 극단(≥80% or ≤20%) → "되돌림 주의"

**한 줄로:** 판단 요약 = "여러 층·체결·위치를 다 합쳐서 지금 분위기가 어느 쪽으로 기울었나 + 조심할 점"을 자동으로 정리해준 것. **그래도 진입은 차트에서!**

# 【④】 인걸핑 알림 + 리테스트 + 품질 점수

## 14. 인걸핑 알림 & 리테스트(되돌림 확인)

**인걸핑(engulfing)** = 직전 캔들을 다음 캔들이 **통째로 삼키는** 모양 = 대표적인 "방향 바뀜/힘 실림" 신호예요. 이게 뜨면 도구가 **알림(텔레그램/화면)** 을 줘요.

### 리테스트가 뭐예요? — "신호 났다고 바로 안 들어감"
인걸핑이 뜬 자리로 가격이 **한 번 되돌아왔다가(리테스트) 다시 방향을 확인**하면 더 좋은 진입이에요.

```
비유 — 문을 밀고 나갔다가, 문이 진짜 열렸나 한 번 당겨보기
  인걸핑 = 문을 밀고 나감 (방향 전환)
  리테스트 = 그 자리로 돌아와서 "여기가 진짜 지지되나" 확인
  → 확인되면 → 더 확실한 진입 자리
```

- 도구는 인걸핑 후 **M15 캔들 최대 4개** 동안 가격이 그 자리(존)로 **다시 오는지** 추적해요.
- ⚠️ **중요(수정된 규칙):** 인걸핑이 끝난 직후엔 가격이 아직 그 존 안에 있어요. 그래서 **"가격이 존을 한 번 벗어난 뒤 다시 돌아왔을 때"만** 리테스트로 인정해요. (안 그러면 신호 나자마자 바로 리테스트로 잘못 뜸)

---

## 15. 인걸핑 품질 점수 — "이 인걸핑 좋은 놈이야?"

### 왜 필요해요?
인걸핑은 하루에도 엄청 많이 떠요. 근데 다 좋은 건 아니에요. 그래서 **"이 인걸핑이 몇 점짜리냐"** 를 숫자로 매겨요.

### 비유 — 소개팅 상대 점수
```
성격 + 취미 + 거리 + 조건 → 다 좋으면 90점, 별로면 40점
인걸핑도: 확실히 삼켰나 + 몸통 꽉 찼나 + 좋은 자리인가 + 큰 방향 맞나
```

> **📐 계산식 & 해석 — 4가지 요소 (합쳐서 0~100점)**
> - **① 삼킴 정도** = 인걸핑 캔들 몸통 ÷ 직전 캔들 몸통 (배수). 1배 살짝 삼킴(약) ~ 2배↑ 확실(강).
> - **② 몸통 효율(방향강도)** = |(종가−시가)÷(고가−저가)|. 몸통 크고 꼬리 짧을수록 高.
> - **③ 레벨 근접** = 인걸핑 가격이 중요한 레벨(일/주간 고저 등)에 **가까울수록** 高.
> - **④ 상위 일치** = H4 방향과 인걸핑 방향이 **같으면** 加點(엇갈리면 감점).
> - → 이 4개를 가중 합산해 0~100점. *(가중치는 조정 가능. 처음엔 대략적인 기준으로 시작.)*

### ⚠️ 중요한 함정 — "내 점수"는 아직 내 생각일 뿐
```
진짜 좋은지는 → 결과(이겼나 졌나)로 검증해야 해요.
  인걸핑마다 점수 매기고 → 승패 기록 → 쌓이면
  "80점은 승률 65%, 50점은 40%" → 점수가 맞으면 "이 기준 믿자"
  상관없으면 → "내 점수 기준 틀렸네, 고치자"
```

### 점수에 따라 행동이 정해져요
```
높은 점수(80↑): "좋은 놈! 적극적으로" → M5 살짝만 되돌려도 진입(선진입)
중간 점수(50~80): "그럭저럭" → M15 확실히 확인 후 M5 진입
낮은 점수(50미만): "허접" → 관망(패스)
```
*(품질 점수 기능은 기본 터미널이 익숙해진 뒤에 켜세요. 처음부터 다 하면 복잡해요.)*

# 【⑤】 자동 기록기 — "내가 언제 이기고 지는지"

## 16. 자동 기록기 (블랙박스)

**여러분이 사거나 팔 때, 그 순간의 모든 상황을 자동으로 저장**하는 기능이에요.

### 비유 — 자동차 블랙박스
```
블랙박스: 사고 순간 자동 녹화 → "왜 사고 났나" 확인
기록기:   매매 순간 자동 저장 → "왜 이겼나/졌나" 확인
→ 여러분이 안 적어도 알아서 다 기록
```

### 뭘 기록해요?
```
'매수/매도' 하는 순간 자동 저장:
  그때 방향강도 / 도달률 / 세션 / 체결 우위 / 인걸핑 품질점수 / ... 모든 숫자
그리고 청산하면 → 이겼는지 졌는지 자동 추가
여러분이 적을 건 딱 하나 → 그때 기분(감정)
→ 파일 두 개로 쌓여요: engulf_log.csv(신호 기록), trade_log.csv(매매 기록)
```

### 왜 중요해요? — 여러분만의 '진짜 실력표(엣지)'
```
기록이 쌓이면 보여요:
  "나는 도달률 낮을 때(자리 많이 남았을 때) 잘 이기네"
  "품질 80점 넘는 것만 들어가면 승률이 확 오르네"
  "런던 세션엔 잘 되는데 뉴욕 세션엔 자꾸 지네"
→ 이게 남이 못 알려주는 '나만의 이기는 조건' = 엣지
```

**이 기록기는 터미널만큼, 아니 더 중요할 수 있어요.** 터미널은 "지금 상황", 기록기는 "내가 이기는 조건". 매매를 '감'에서 '데이터'로 바꿔줘요.

# 【⑥】 대시보드 & 모바일 앱

## 17. 폰에서 실시간으로 보기

위 모든 정보(방향강도·체결·판단 요약)를 **폰 한 화면에서 실시간**으로 봐요.

### 어떻게 데이터가 흘러요?

## 19. 실전 — 이 화면 보고 어떻게 판단해요?

터미널을 보고 판단하는 순서예요.

```
[화면 상황]
  판단 요약: 하방 우위, 다층 정렬 4/4
  주간↓ / 일간↓ / 세션 방향강도 −98% (평균 34%)
  H4: 완성 −38% 추세 하락, H1위치 41%
  일간 도달률: 40%
  체결(4H): 매도 우위 −3.2%, -1봉→진행봉 매도 강해짐
  세션: 런던 (활발)

[1단계] 큰 방향 (판단요약/주간/일간/H4)
  → 다 하락 + 정렬 4/4 → "오늘은 파는 것(숏)만 보자"
[2단계] 센가? (방향강도 vs 평균)
  → 98% > 34% → "강한 추세. 좋다"
[3단계] 자리 남았나? (도달률)
  → 40% → "아래로 더 갈 여력 있음. 늦지 않음"
[4단계] 체결이 밀어주나? (체결 우위/효율/시계열)
  → 매도 우위가 시간 갈수록 강해짐 → "하락에 힘이 실림 (신뢰↑)"
[5단계] 활발한가? (세션/틱볼륨)
  → 런던 세션 → "활발. 움직임 기대"

[종합]
  "큰 방향 하락 + 강한 추세 + 자리 남음 + 체결도 매도 + 활발
   → 숏 기회를 찾기 좋은 상황"
  → 이제 차트에서 실제 진입점(인걸핑)을 찾는다
```

⚠️ **다시 강조:** 터미널은 "상황이 좋다"까지만. **언제 들어갈지는 차트(인걸핑)를 보고 여러분이 판단**합니다.

## 20. 언제 쉬어야 하나

```
[쉬는 예 1 - 횡보]   방향강도 15%(평균 34%) → 밍밍. "휩쓸려 물린다. 쉬자"
[쉬는 예 2 - 엇갈림] 주간↑/일간↓/세션↑ or 판단요약 '혼조' → "애매. 확실해질 때까지"
[쉬는 예 3 - 과도]   도달률 130% or H1위치 90% → "너무 감. 되돌림 맞는다. 쉬자"
[쉬는 예 4 - 조용]   틱볼륨 10%, 아시아 세션 → "잘 안 움직임. 답답하게 있느니 쉬자"
[쉬는 예 5 - 체결 상충] 가격은 오르는데 체결은 매도 우위 → "힘 안 실림. 의심. 기다려"
```
**핵심:** 좋은 트레이더는 "안 하는 것"도 실력. 애매하면 쉬는 게 정답일 때가 많아요.

## 21. 자주 하는 오해 (조심!)

```
❌ "터미널이 하락이라니까 무조건 팔면 되겠지?"
   → 아니에요. 터미널은 '상황'만. 진입은 차트(인걸핑) 보고.
❌ "방향강도 높으니까 지금 당장 들어가자!"
   → 방향강도는 '추세다'만 알려줌. '어디서(자리)'는 도달률·레벨로 따로.
❌ "도달률 100% 넘었으니 계속 가겠네, 더 따라가자!"
   → 위험. 100% 넘음 = 너무 감 = 되돌림 조심.
❌ "체결 우위가 +니까 무조건 오르겠지?"
   → 참고 지표예요. 방향강도·정렬이랑 '같이' 볼 때 의미. 왜곡 많으면 신뢰↓.
❌ "대시보드만 보면 차트 안 봐도 되겠다"
   → 절대 안 돼요. 대시보드=보조, 차트(캔들/인걸핑)=본체.
```

## 22. 📐 계산식 총정리 (한 곳에 모아보기)

| 값 | 계산식 | 한 줄 해석 |
|---|---|---|
| 방향강도 | (종가−시가)÷(고가−저가)×100 | +위/−아래, 클수록 추세 |
| 추세율(효율) | \|방향강도\| | 방향 빼고 세기만 |
| 시가대비(%) | (현재가−시가)÷시가×100 | 시작 대비 등락률 |
| 변동 고저(핍) | (고가−저가)÷1핍 | 출렁인 총거리 |
| 변동 시종(핍) | (종가−시가)÷1핍 | 순수 이동거리 |
| 평균 | 최근 N개 방향강도 절댓값 평균 | 평소보다 센지 비교 기준 |
| 평균 상방폭 avgUp | 최근 N기간 (고가−시가) 평균 | 위로 평소 이만큼 |
| 평균 하방폭 avgDn | 최근 N기간 (시가−저가) 평균 | 아래로 평소 이만큼 |
| 세션 1차 레벨 | 시가 ± 0.5×평균폭(상/하) | 절반 목표 |
| 세션 최종/일·주 레벨 | 시가 ± 1.0×평균폭(상/하) | 전체 목표 |
| 도달률(%) | (현재가−시가)÷(레벨−시가)×100 | 목표 대비 얼마나 감 |
| 도달률 잔여/초과 | (레벨−현재가) / (현재가−레벨) 핍 | 남은/넘어간 거리 |
| 틱볼륨(%) | 현재 틱수÷평소 평균 틱수×100 | 평소 대비 활발도 |
| H1 위치(%) | (현재가−5일저가)÷(5일고−5일저)×100 | 0바닥~100천장 |
| 체결 우위(%) | (매수틱−매도틱)÷총틱×100 | +매수/−매도 압력 |
| 실이동(핍) | 종가−시가 | 순수 이동 |
| 고저폭(핍) | 고가−저가 | 출렁임 |
| 효율(0~1) | \|실이동\|÷고저폭 | 1=깔끔한 한방향 |
| 틱당 실이동 | 실이동÷총틱 | 거래당 추진력 |
| 편향(표결) | 상승층수 − 하락층수 (세션·일·주·H4) | +2↑상방/−2↓하방/그외 혼조 |
| 다층 정렬 | 우세방향과 같은 층 개수 /4 | 4/4=강함 |
| 인걸핑 품질 | 삼킴배수+몸통효율+레벨근접+상위일치 (0~100) | 높을수록 좋은 신호(단, 승패로 검증) |

## 23. 한 장 요약 (이것만 기억하세요)

```
PIPxLOT = 지금 상황 알려주는 도구 세트 (사라/팔아라 아님!)

핵심 값:
  ① 방향강도 = 추세냐(높음) 횡보냐(낮음) + 방향(+/−)
  ② 평균 대비 = 평소보다 센가
  ③ 도달률 = 목표까지 얼마나 (100% 넘으면 조심)
  ④ 틱볼륨/H1위치 = 활발한가 / 5일 범위 어디쯤
  ⑤ 세션·일간·주간 = 큰 방향과 지금이 같은가 (→ 다층 정렬)
  ⑥ 체결 우위·효율·틱당실이동 = 그 움직임을 거래가 밀어주나
  ⑦ 판단 요약 = 위를 다 합친 편향 + 조심할 점 (한 줄)

판단 순서:
  판단요약/큰방향 확인 → 센가(평균) → 자리 남았나(도달률)
  → 체결이 밀어주나 → 활발한가(세션) → 좋으면 "차트에서 인걸핑 찾기"

품질 점수 & 기록기:
  좋은 인걸핑만 골라 들어가고(점수) → 결과를 자동 저장(기록기)
  → 나만의 '이기는 조건(엣지)'을 데이터로 찾음

절대 규칙:
  도구 = 보조 (상황만) / 차트(캔들·인걸핑) = 본체 (실제 진입)
  애매하면 = 쉬기 (안 하는 것도 실력)
```
