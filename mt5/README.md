# 인걸핑 전략 지원 지표 세트 (MetaTrader 5 / MQL5)

EURUSD 데이트레이딩(MTF Engulf 전략)을 위한 **MT5 전용** 지표·알림·자동기록기 모음입니다.
[PRD](../docs/) 명세를 그대로 구현했습니다.

> **철학** — 가격(캔들)이 메인, 지표는 보조. 진입 판단은 캔들(인걸핑)에서 나오고,
> 이 지표들은 "지금 어떤 맥락(국면/방향/매수세)인가"만 제공합니다.
> 자동매매(EA)가 아닙니다. 진입은 사람이 결정합니다.

---

## 구성 파일

```
mt5/
├── Include/Engulf/            # 공용 라이브러리 (.mqh) — MQL5/Include/Engulf/ 에 복사
│   ├── Common.mqh             #   핍환산·방향강도/효율·경과율·세션판정(KST)·포맷
│   ├── Stats.mqh              #   기간별 고저폭/방향강도/틱볼륨 평균, 세션 히스토리
│   ├── Ticks.mqh              #   CopyTicks 집계 (Up/Down/왜곡, 체결우위)
│   └── Engulf.mqh             #   인걸핑 감지(Inthebox·멀티캔들) + 품질 점수
│
├── Indicators/                # 커스텀 지표 (.mq5) — MQL5/Indicators/ 에 복사
│   ├── DirectionStrengthTerminal.mq5   # 지표 A — 방향강도 터미널 (1순위)
│   ├── ExecutionTerminal.mq5           # 지표 B — 체결 터미널 (3순위)
│   └── EngulfAlert.mq5                 # 인걸핑 알림 + 리테스트 추적 + engulf_log.csv
│
└── Experts/                   # EA (.mq5) — MQL5/Experts/ 에 복사
    └── TradeSnapshotLogger.mq5         # 지표 C — 진입 스냅샷 자동 기록기 (★핵심)
```

`Include/Engulf/` 의 `.mqh` 는 4개 소스가 공유합니다. 반드시 함께 복사하세요.

---

## 설치 (VPS의 MT5 기준)

1. MT5 상단 메뉴 **파일 → 데이터 폴더 열기** → `MQL5` 폴더로 이동
2. 아래처럼 복사

   | 원본 | 복사 위치 |
   |---|---|
   | `mt5/Include/Engulf/*.mqh` | `MQL5/Include/Engulf/` |
   | `mt5/Indicators/*.mq5` | `MQL5/Indicators/` |
   | `mt5/Experts/*.mq5` | `MQL5/Experts/` |

3. **MetaEditor** 에서 각 `.mq5` 를 열고 **F7(컴파일)**.
   (`.mqh` 는 직접 컴파일하지 않습니다 — `.mq5` 컴파일 시 자동 포함)
4. MT5 **탐색기(Navigator)** 에서 지표/EA 를 EURUSD 차트에 드래그.
5. EA(`TradeSnapshotLogger`)는 차트 우상단 스마일 아이콘이 **활성**(자동매매 허용)이어야
   `OnTradeTransaction` 이 동작합니다. (이 EA 는 주문을 내지 않고 기록만 합니다.)

> 사용자는 모바일/태블릿에서 VPS 원격 접속(RDP 등) 또는 MT5 모바일로 동일 계정 접속하여
> 조회합니다. 커스텀 지표의 화면 표시는 VPS 화면 기준입니다.

## ⚙️ 필수 설정: 서버-KST 시차 (`InpServerToKST`)

모든 지표/EA 공통 입력값입니다. **KST = 서버시간 + `InpServerToKST` 시간**.

- HFM 등 브로커 MT5 서버는 보통 **GMT+2 / GMT+3**. KST 는 GMT+9.
  - 서버가 GMT+2 → `InpServerToKST = 7`
  - 서버가 GMT+3 → `InpServerToKST = 6`
- 확인법: MT5 시세창의 서버 시각과 실제 KST 를 비교해 차이를 입력.
- **서머타임**: 초기 버전은 KST 고정 방식(오차 감수)입니다. 서버가 DST 로 바뀌면
  값을 1 조정하세요. (추후 자동화 예정)

세션 정의(KST 고정): 아시아 09–16 / 런던전반 16–19 / 전환 19–21:30 /
뉴욕전반 21:30–00:30 / 뉴욕후반 00:30–06:00.

## 각 파일 설명

### 지표 A — 방향강도 터미널 `DirectionStrengthTerminal`
차트 좌상단에 **세션 / 당일 일간 / 이번주 주간 / H4 국면** 4개 층을 상시 패널로 표시.
타이머(기본 5초)로 갱신합니다.

- **방향강도** = (종가−시가)/(고가−저가)×100 [부호 유지] — 양수=상승, 절댓값=강도
- **국면** = |방향강도| > 최근 평균 → 추세 / < 평균 → 횡보
- **레벨** = 시가 ± (평균 고저폭 R × 배율). 1차 0.5 / 최종 1.0 (`InpLevelMid/Full` 로 조정)
- **도달률** = (현재가−시가)/(레벨−시가)×100 — 100 미만=여력, 초과=돌파
- **틱볼륨** = 현재 틱수 / 최근 N기간 평균 ×100 (막대 표시)
- 층별 on/off 파라미터 제공. H1 위치(5일 범위%)는 중복 방지를 위해 H4 블록에 배치.

### 지표 B — 체결 터미널 `ExecutionTerminal`
`CopyTicks()` 로 호가 틱을 받아 매수/매도 체결을 집계. 차트 우상단 패널.

- **[1] 4H 요약**: 누적틱·왜곡, 순 방향성(체결우위)%, 4H 순이동·고저폭
- **[2] 진입 프레임(기본 M5)** / **[3] 자리 프레임(기본 H1)**: 직전 완성봉 vs 진행봉 대조
  - 총틱/왜곡, 방향성 우위%, 실이동, 흔들림, **효율**=|실이동|/흔들림, 틱당 실이동
- **체결우위** = (Up틱−Down틱)/총틱×100
  - Up = 매수(`TICK_FLAG_BUY`), Down = 매도(`TICK_FLAG_SELL`)
  - 브로커가 flag 미제공 시 **bid/ask 근접 추정**으로 자동 대체 (패널에 "추정" 표기)
- **왜곡** = bid 또는 ask 한쪽만 갱신된 비정상 틱 수(근사). 정의 확정 전 참고용.

### 인걸핑 알림 `EngulfAlert`
H1(조정 가능) 인걸핑을 감지해 **알림(팝업 + 모바일 푸시)** + **품질 점수** + **CSV 기록**.

- **인걸핑 정의(Inthebox)**: ① 현재 몸통이 직전 몸통 완전 삼킴 ② 진입방향 꼬리도 직전 꼬리 삼킴.
  1캔들에 못 삼켜도 2~3캔들이 모여 삼키면 인정(멀티캔들, `InpMaxLegs`).
- **품질 점수(0~100)**: ①삼킴비율 ②캔들방향강도 ③레벨근접 ④상위(H4)일치 ⑤체결일치 정규화 가중합.
  - ⚠️ 가중치 기본값 = **균등(모두 0 → 자동 균등)**. PRD 원칙대로 '감'이 아니라
    데이터로 정합니다. `engulf_log.csv` 를 쌓아 상관분석 후 `InpW_*` 로 재분배하세요.
- **리테스트 추적**: 인걸핑 확정 후 M15 4개(`InpRetestBars`) 안에 가격이 존(시가~종가)에
  재진입하면 "리테스트 도달" 알림(진입후보/손절/익절 2:1 표시). 4개 넘으면 "무효".

### 지표 C — 진입 스냅샷 자동 기록기 `TradeSnapshotLogger` (★핵심)
표시가 아니라 **데이터 수집 엔진**. 포지션이 열리는 순간(`OnTradeTransaction`)을 감지해
그 시점의 모든 터미널 수치를 스냅샷으로 `trade_log.csv` 한 줄에 기록하고,
청산되면 결과(승패·손익·보유시간·R배수)를 **같은 행에 자동 추가**합니다.

- 수치 = 자동 / 결과 = 자동 / **감정(emotion 컬럼) = 사용자 수동**
- `engulf_id` 컬럼으로 `engulf_log.csv` 와 조인 가능 → "이 품질의 인걸핑이 실제 어떤 결과였나"
- 데모/실계좌 태그(`account`) 자동 기록.

## CSV 파일

MT5 `데이터 폴더/MQL5/Files/` 에 생성됩니다.

| 파일 | 생성 주체 | 목적 |
|---|---|---|
| `engulf_log.csv` | `EngulfAlert` | 모든 인걸핑 신호(진입 무관). 신호 분석·품질점수 검증 |
| `trade_log.csv` | `TradeSnapshotLogger` | 실제 진입만. 결과·감정 포함. **내 엣지 발견의 데이터 소스** |

두 파일을 `engulf_id` 로 조인하면 "품질 80+ 인걸핑 중 진입한 것들의 승률" 같은 분석이 가능합니다.

> **엣지 발견이 목적**: "남의 승률이 아니라 내 실행 데이터가 진짜". 표본이 쌓이면
> 이긴 거래 vs 진 거래의 방향강도·도달률·품질점수·세션 분포를 비교해
> "나는 어떤 수치 조합일 때 잘 이기는가"(=내 엣지 조건)를 찾고,
> 그 결과로 품질점수 가중치를 재조정합니다(피드백 루프).

## 주의사항 / 한계 (PRD §4)

- **티커 자동**: `_Symbol` 사용 → 차트 종목을 바꾸면 그 종목으로 재계산. 핍 환산도 `_Digits` 자동.
- **CopyTicks 제약**: 과거 틱 보관량은 브로커에 따라 제한적. 실시간·근접 과거 위주로 사용.
  틱이 비면 지표 B [1] 4H 요약에 "틱 데이터 없음"으로 표기됩니다.
- **BUY/SELL flag**: 브로커 미제공 시 bid/ask 근접 추정으로 자동 대체(정확도 하락 감수).
- **성능**: 매 틱 전면 재계산하지 않습니다. 신규 봉 또는 타이머 주기로만 갱신.
- **세션/서머타임**: `InpServerToKST` 로 수동 보정. DST 전환 시 값 조정 필요.
- **레벨 배율(0.5/1.0)**: 원작자 캡처값이 있으면 역산해 보정. 없으면 기본값으로 시작 후 조정.

## 범위 밖 (하지 않음)

자동매매 로직 · 자동 진입/청산 · 지표만으로 진입 신호 확정 · 계산식 불명확한 항목.
지표는 맥락만 제공하고, 진입은 캔들(인걸핑)에서 사람이 판단합니다.
