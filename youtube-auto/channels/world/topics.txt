# Mr.Untold 소재 — 가볍고 재미있는 "만약에?" 위주. 무겁고 어두운 역사·경제·정치는 피한다.
# 핵심: "우와 신기해/재밌다" 가 나오는 상상. 과학·자연·동물·우주·일상·모험.
# '#' 줄 무시. 사실 토대는 검증, 분기 이후는 '추정'임을 명시. 쉬운 말.
# (continent 는 이야기와 가장 관련 깊은 대륙으로 태깅 — 지구 전체면 사건 배경 기준.)

# === 과학 · 우주 (재미/경이) ===
What if the Moon suddenly vanished? (space / Earth)
What if the Earth stopped spinning for five seconds? (space / Earth)
What if Earth had rings like Saturn? (space / Earth)
What if a day lasted 48 hours? (space / Earth)
What if gravity were only half as strong? (science / Earth)
What if humans could photosynthesize like plants? (science / Earth)
What if the oceans were made of fresh water? (nature / oceans)
What if the Sahara were still a green jungle? (nature / Africa)

# === 동물 · 자연 (재미/경이) ===
What if the dinosaurs never went extinct? (nature / deep time)
What if humans had tails? (biology)
What if cats were the size of tigers? (animals)
What if insects grew as big as dogs? (animals)
What if we could understand what animals are saying? (animals)
What if whales walked back onto land? (nature / oceans)

# === 일상 · 사람 (가벼운 상상) ===
What if we never needed to sleep? (everyday)
What if everyone on Earth jumped at the exact same time? (everyday / Earth)
What if the whole world spoke one language? (society)
What if humans could breathe underwater? (biology / oceans)
What if we never invented the wheel? (everyday / tech)

# === 역사·모험 (가볍고 신나는 각도만) ===
What if China's giant treasure fleet never stopped sailing? (China / Asia)
What if the Vikings had settled America for good? (Norse / Americas)
What if the Great Pyramid still had its shiny white casing today? (Egypt / Africa)
What if the Library of Alexandria never burned? (Egypt / knowledge)
What if Australia's giant animals never disappeared? (Australia / Oceania)
